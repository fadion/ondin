# Phosphor icon name -> codepoint, for the bundled Phosphor.ttf (Regular, 2.1.1).
#
# Phosphor.ttf's `post` table is version 3.0, which stores no glyph names at all,
# so names cannot be read from it (the table itself is present — this line said
# "has no `post` table" until it was measured, and the tag is one grep away). This
# table was recovered from the font's own GSUB *ligatures*, which map each icon's
# name (spelled out of ASCII glyphs) to its PUA codepoint; see the "Adding an
# icon" note in `src/theme.rs`. Every constant in `theme.rs` was checked against
# it, so it is trustworthy — with one caveat below.
#
# CAVEAT: single-word names are absent. A ligature needs two or more input
# glyphs, so `x`, `check`, `circle`... never appear in the ligature table at all.
# Phosphor assigns codepoints alphabetically in runs of two, so recover those
# from their neighbours here (e.g. `x` is the unclaimed slot between `wifi-x`
# U+E4F4 and `x-circle` U+E4F8, hence U+E4F6).
#
# Regenerate: parse the GSUB ligature sets with ttf-parser (feature
# "opentype-layout"), building gid->char from the ASCII cmap range and
# gid->codepoint from U+E000..U+F900; ligature set `i` belongs to the `i`-th
# glyph in coverage order.
