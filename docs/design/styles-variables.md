# Styles and variables (§5.3f)

Variables (named, typed, per-mode values that fields bind to) and styles (reusable per-slot sets of values), including how kits carry both, the binding chrome, and the commit-time passes that keep bindings honest. Text styles and the text node itself are in `text.md`; components and overrides are §5.3d.

## 5.3f Styles and variables

### Variables

A **variable** is a named, typed value — **colour, number, string or boolean** — with **one value per mode**. An **alias** is a per-mode cell naming another variable of the same type (not a fifth type). CSS custom properties are the model.

**Modes**
- One mode list per document, no collections; the default mode is the first.
- Only a **frame** sets a mode (never a group), exactly one; `Node::mode: Option<ModeId>`, `None` inherits from the nearest ancestor frame that sets one, else the default. Set only on an `Artboard`.
- On an instance, a mode set on the copy is an override like any field (§5.3d).
- Deleting a mode returns every frame set to it to inherit, in one undoable transaction.
- A kit's variables use the kit's own modes, mapped onto the document's through one per-kit mapping held at document level (below). A frame may be set to a kit's own mode (a kit main's, carried to its instances); it governs only that kit's variables, and `mode_at` passes over it.

**What binds**
- **Numbers**: W, H, corner radius, layer opacity, stroke width, an effect's X/Y/blur/spread, layout gaps and padding. **Not** X, Y or rotation (placement, which an instance keeps as its own — `reset::placement_is_own`).
  - W/H bind only where the user set them (never a hugging frame's, a text box's, or a size a flex/grid layout deals out or stretches).
  - Opacity binds as a percentage 0–100 (*40* draws 0.4).
  - A stroke's width binds in the item, one stroke at a time, and not where the stroke draws per-side widths.
  - An effect's numbers bind in the item, each only where the kind has that number (a layer blur's radius is the blur).
- **Colours** bind a whole solid paint, never a gradient stop (a reusable gradient is a fill style). The variable carries its own alpha; the fill's `%` stays a separate unbindable field and what draws is the variable's colour times it.
- **Booleans** bind visibility.
- **Strings** bind text content and font family. Binding the content clears its spans (a string's length changes with the mode). A text style holds a plain family, never a variable.
- A field that is also a component property's needs no rule: the property is a view over the field (§5.3d).

**A bindable field stores its binding and resolves it at read.** It holds `Literal(T) | Bound(VarId)`; the value drawn is found against the mode in force at that node. Consequences:
- Overrides compare the binding: a main rebinding *brand* → *accent* reaches a copy still bound to *brand*; a copy bound elsewhere keeps an override.
- Editing a variable writes no node, so nothing propagates.
- §12's "resolved value is in no node" holds, where §5.3d's copies bend it.
- Every reader must resolve (`container::lay_out`, `scene::build`, the SVG writer, the snapshot, the inspector); one that skips it draws the fallback silently. Paint is guarded by a type with no `Deref`; other fields by `Document` resolve readers.

**Deletion and leaving a document**
- Deleting a variable in use **detaches** every field bound to it to the value it resolved to, as ops in the deleting transaction (same as a deleted main, §5.3d). Deleting a style detaches its users likewise.
- A paste into another document rebinds to a variable of the same name and type, else detaches to the resolved value; within a document the binding is kept. *Paste properties* lands by the same rule through `variable::rebind`; presets hold nothing bindable.
- A ghost (drag preview) resolves in the default mode (paint and visibility); the snapshot reports the resolved value, not the binding.

### The table and the readers

`ondin_core::variable`: `Variables { modes, vars }` — modes in order, variables by `VarId`; `ModeId`/`VarId` are `NodeId` newtypes from the session's `IdSource`. Each variable is a name, a kind (`Color`, `Number`, `Boolean`, `String`) and one `Cell` (value or `Alias`) per mode. `Document::variables` reads it.

Readers built on `mode_at` (which counts the node itself): `resolve_var`, `resolve_brush`, `resolved_paint`, `resolve_corners`, `resolved_display`, `shown`, `resolved_kind` (applies `text_drawn_in`), `drawn_opacity`, `stroke_width_drawn_in`, `resolved_effects`.

**`variable::check` is a post-condition of every transaction and a check of the loader**; it refuses a dangling binding rather than repairing it. Save format: v7/v8 (§5.11); operations, invalidation and the paste rule are in §5.7, §5.11, §5.9.

### The binding shapes

Ten shapes. Each "keep" pass runs in `commit_inner` in the order listed and judges a write over a bound field so no door has to know about bindings.

| Field | Storage | Literal while bound | Reader | Commit pass |
| --- | --- | --- | --- | --- |
| Paint | `Fill::brush`/`Stroke::brush` = `BrushSource::{Literal(Brush), Bound{var, alpha}}` | n/a (`%` rides in `alpha`) | `resolved_paint`, then `BrushSource::drawn` (bound = transparent; use only below a resolve) | decided at the write |
| Corners | `Node::corner_vars: [Option<VarId>;4]` beside `Rect`'s radii | 0 | `resolve_corners`; `Resolved`'s used kind | `keep_corner_bindings` |
| Gaps/padding | `Node::spacing_vars: [Option<VarId>;6]` (col gap, row gap, pad T/R/B/L) | 0 | `Document::resolved_display` (a `Cow`) behind `LayoutView::display` | `keep_spacing_bindings` |
| Visibility | `Node::visible_var` beside `visible` | `true` | `Document::shown` (layer's own eye, not ancestors') | `keep_visible_bindings` |
| Opacity | `Node::opacity_var` (number, percent, clamped 0–100) | 0 | `Document::drawn_opacity` | `keep_opacity_bindings` |
| Stroke width | `Stroke::width_var` in the item | 0 | `resolved_paint_in` substitutes and clears `width_var` in its output | `keep_stroke_width_bindings` |
| Effect numbers | `Effect::vars: EffectVars` (X, Y, blur, spread) in the item | 0 | `resolved_effects(_in)` substitutes and clears bindings | `keep_effect_bindings` |
| W/H | `Node::size_vars: [Option<VarId>;2]` for `Artboard`, `Rect`, `Ellipse`, `Polygon`, `Star` | 0 | `LayoutView::kind` via `Document::resolved_kind`; `resolve::with_bound_size` for unlaid layers | `keep_size_bindings` |
| Text content/family | `Node::text_vars: [Option<VarId>;2]`, string vars, `Text` only | empty (no spans, no paragraph spans; runs' families cleared) | `resolved_kind` (`text_drawn_in`); `with_bound_size` | `keep_text_bindings` |
| Frame mode | `Node::mode` | — | `mode_at` | — |

Per-shape rules:
- **Corners.** A bound corner's literal is 0; readers of the document's own kind see 0, so the inspector reads corners as drawn. A write over a bound corner detaches it, **except** a corner written what it draws *or* its own literal (put back to 0) stays bound — both halves are load-bearing (a field reads drawn values and writes them back; Scale and per-corner reset build from literals) and either alone detaches untouched corners. Price: a 0 typed into the field detaches nothing; the chip's retype (which detaches first) is 0's door. Only `Rect` corners bind; a `Path`'s per-anchor radii don't, by decision (indexed by anchor, which point editing inserts/deletes).
- **Gaps/padding.** A layout taken away clears its bindings; a binding on a layout-less node is inert. The spacing and corner judgements are functions the preview shares (`build::kept_spacing_vars`, `kept_corner_vars`) so a write the commit detaches previews where it lands. The literal half carries most writers here (the Container card writes one slot over the committed layout; flex↔grid switch and Scale keep the rest).
- **Visibility.** Everything that draws, picks, lays out or exports asks `shown`, so a layer its variable hides leaves its layout's flow. Judged by **one half only**: written what it shows stays bound; anything else detaches. The literal half is omitted because it would excuse the `true` the eye and *Bring back into flow* write to show a hidden bound layer, keeping it bound and hidden.
- **Opacity.** One half only (the drawn value), because 0% typed over a bound layer means "make it invisible". No writer builds an opacity from the literal. Chip is on one layer's Appearance card only; the several-layer row writes the outermost members' shared value and takes no binding, detaching in the edit itself.
- **Stroke width.** Preview bounds, hit test, snapshot, ghost (resolved at capture, default mode) all read through `resolved_paint_in`; clearing `width_var` on output matters because a preview override holding a resolved paint is resolved again by the scene against the committed table. Judged by the corners' two halves (`kept_stroke_widths`, shared with the preview): a stroke whose binding the write carries unchanged stays bound when written the drawn width or its literal 0 (literal half load-bearing: every Stroke-card edit and Scale rebuild the whole list from stored items); a binding the write changes (bind, detach, reset, new stroke) is left as written. A `Custom`-sides stroke on a **box** (`build::draws_own_sides` via `geometry::effective_sides`) takes no binding: `bind_stroke_width_ops` refuses it and `kept_stroke_widths` detaches a bound one at the width it drew, whoever wrote it (checked before the "binding the write states" exemption, so a pasted bound `Custom` stroke lands detached). On an ellipse or path `Custom` draws whole at `width` and binds normally. The shared weight row clears bindings it writes, except a stroke whose bound width already draws the typed one. The pass rewrites lists in place.
- **Effect numbers.** `resolved_effects` floors a blur at 0, offsets/spread not at all; a bound number is never capped. Judged by corners' two halves (`kept_effect_vars`, shared with preview); a binding on a number the effect's kind no longer has (shadow retyped to layer blur) is dropped whoever wrote it. Chip on one layer's own effect; popover fields over several layers stay plain and clear the slot's binding in their write. The retype range is the card's own (blur `0..=MAX_BLUR`, offsets/spread `±MAX_OFFSET`). The pass rewrites in place.
- **W/H.** Only a hand-set axis binds (`build::size_axes_authored`): not `%`/`fit-content`, not pinned at both ends, not a flex item's main axis with growth/basis, not a stretched flex cross axis or grid axis sized `auto` (shrink, min-, max- don't count). `keep_size_bindings` judges `Size` writes by the corners' two halves (`kept_size_vars`): the resized axis detaches, the other stays bound, and an axis an edit makes computed (keyword, second pin, growth, basis, stretch, reparent into a layout) detaches to the size drawn before. `keep_insets` reads sizes from the document this pass leaves. Binds on one layer's Transform card only; text boxes' W/H don't bind.
- **Text.** Binding writes both literals empty and no family binds under a text style. A `SetText` of the drawn string with no spans stays bound (one half; `""` is what a deliberately emptied text writes); anything else detaches. Spans written over a bound content become a `SetText` of the drawn string, detaching. A family written drawn or `""` stays bound, another detaches; applying a text style detaches it. A run given a family is a span, the default staying bound under it. A copy's family binding under its main's text style is cleared by `style::settle`. `keep_insets` reads the document both passes leave.

Passes in order: `keep_corner_bindings`, `keep_spacing_bindings`, `keep_visible_bindings`, `keep_opacity_bindings`, `keep_stroke_width_bindings`, `keep_effect_bindings`, `keep_size_bindings` (after visible), `keep_text_bindings` (after size). All before `propagate::owed`.

**Saying what was cut.** Passes that append `Set*Vars` ops are read by `session::variables_detached` between `asked_ops` (noted after `keep_flex_sizes`, before the first pass) and `propagate::owed`'s mark; it names every variable a slot loses (*Detached size/w*, *Detached N variables*) beside `styles_detached`, merged as `said_detached`. The stroke-width and effect passes rewrite in place and append nothing, so `commit_inner` notes the bound stroke widths/effect numbers before and the cut ones after (`stroke_widths_bound`/`_cut`, `effect_numbers_bound`/`_cut`) and merges the names. Edits whose own ops set a binding say nothing; inspector doors detach in the edit and say nothing; the layers panel's eye and the hide chord are left to the pass and say it. The run ends before the follows (those are consequences in copies). A paint's binding is decided at the write, so the one canvas door that overwrites a bound paint (`replace_image_fill`, a picture dropped/pasted on a shape) reads the fill's variable first and folds it with `EditorSession::last_detached` into its *Replaced with ‹file›* status; the inspector's *Replace image…* and *Paste properties* report likewise (`OndinApp::replaced_status`). The image card is read-only under a styled Fill card.

### Styles

A **style** is one slot's isolated set of values (an isolated CSS class, not the cascade). **Slots: fills, strokes, effects, text, layout.** A node holds at most one style per slot; styles don't stack. A style's values may be variables.

- **A card is styled or not as a whole**: editing any field of a styled card detaches it; no partial override, no inheritance.
- **The inspector is read-only on a styled card** (fully or partly styled alike); a style's values change only through the browser's *Edit*, live to every user. Every other door (canvas gesture on a styled or bound value, *Paste properties*, MCP) detaches, and the floating status says what was detached — refusing would leave canvas handles dead.
- **A layout style** carries the container's whole `Display` (flex or grid, tracks included) and gap/padding bindings — never an item's grow or `align-self`.
- **A text style** holds the character defaults less colour and language (colour is the Fill card's, language the words'), neither the paragraph nor block scope, and a plain family. Spans stay the text's own marks over the style: styling a selection keeps the style; only a write of the defaults detaches.
- **A style is not resolved at read.** A styled layer's own list holds a copy of its style's values, which the commit writes; readers of fills, strokes, effects or type never ask the style table (the opposite of variables).

#### Table and ops

`ondin_core::style`: `Styles` by `StyleId` (a `NodeId` newtype) on `Document`; `Style` = name + `StyleValue`. Names are slash paths, unique within a slot, not across slots. Bindings: `Node::styles: StyleRefs { fills, strokes, effects, text, layout }`. Binding ops per slot (`SetFillStyle`, `SetStrokeStyle`, `SetEffectsStyle`, `SetTypeStyle`, `SetLayoutStyle`) write the binding alone.

`StyleValue`:
- `Fills`/`Strokes`/`Effects`: the card's whole `Keyed` list (a stroke style carries width, join, cap, dashes, alignment).
- `Text(Box<TextStyle>)`: the type part (`style::type_part`: defaults with `color` and `locale` cleared). The commit writes it as `SetTextStyle { spans: None }` over the layer's own colour and language, compares type parts, and re-states spans against the new defaults (a span the new defaults equal is dropped; only `Ctrl+Z` brings it back). `SetTextSpans`/`SetText` are not the slot's writes; `SetTextStyle` is but detaches only when it moves the type part. `style::check` refuses a text style on a non-text layer.
- `Layout(Box<LayoutStyle { display, spacing_vars }>)`: the only slot written by two ops (`SetDisplay`, `SetSpacingVars`; `StyleValue::write_ops`, `writes_slot` maps both). A layout-less layer has no layout value (`StyleValue::of` → `None`), so no style is made from one; **applying a layout style to a plain frame gives it the layout**. Only frames and groups bind one. `edit_through` builds the edited value from the user's display and bindings with each write applied, judging a `SetDisplay` by `kept_spacing_vars` as the commit's spacing pass would (that pass never sees a write folded into the style).

#### `style::settle`

`style::settle` is the whole of "styled or not as a whole". Run by `propagate::owed` **first and last**, it finds every bound slot not holding its style's look (values compared, item ids not) and:
- **rewrites** it from the style when the transaction edited the style or set that binding, or when no op of the user's edit or the doors' rewrites wrote the slot (a component follow, a paste rebound by name);
- **detaches** the layer (values kept) when one did.

So canvas, *Paste properties* and MCP detach with no door knowing. Both runs matter: the first lets a main's rewrite/detach reach copies, the second restores a copy on another style that a follow drifted. After any `settle` call that writes a `SetDisplay`, `propagate::owed` runs `keep_size_bindings` again over the whole transaction (settle's write lands after the door passes), so a child's bound W/H that the style's layout makes computed detaches.

`style::check` (post-condition of `apply` and the loader): names unique per slot; no item id twice in a style; paints bound to colour variables only; stroke width and effect numbers bound to number variables only and only where the kind has them; layout style gaps/padding to number variables only; every binding names a style of its slot; **no vault node bound to a style of the document's own** (a vault node's styles are kits', and a kit's style reads only kits' variables).

Deletion: a bare `RemoveStyle` of a style in use is refused; `style::remove_ops` detaches users first. Deleting a variable a style's paint reads detaches the style to its colour **in the default mode** and rewrites the users from it (they stay styled; a user in another mode changes colour). A paste rebinds a style by id, else by name+slot, else detaches.

### Chrome

**Binding chrome rules**
- A fully rounded **capsule means a reference** (a bound field's chip, a collapsed styled card, an alias); nothing else in the inspector is round. No hue; the accent still means selected.
- A bound field is a **chip** at the field's own width showing the variable name (elided by whole groups from the left), tooltip *name · value · Mode*; a typed literal, `Backspace`, or the chip's hover × detaches; it does not scrub (no scrub arrows; a bound number draws the unbound field's own prefix — `ui::prefix_strip`/`paint_prefix` — under the plain arrow).
- *Mixed* is a capsule (A4) only when every target is bound to different variables (`field_mixed_vars`; tooltip lists names, no hover × or field menu); some bound, some not stays the plain grey *Mixed*. Sits beside §5.3d's override dot.
- **Binding is by typing `--`** into the field; it takes the whole field (`--x * 2` is refused: `expr.rs` is a calculator with no names). `--` opens the one shared list (`panels/binding.rs`), filtering by substring, previewing live (a corner's as the radii it will draw via `absorb` patching a `SetCornerVars`), and is a rung of `Escape`. **B4's refusal**: a whole name with more after it (`binding::refused`, asked only once nothing matches) turns the list into one sentence and dims the refused tail with a dotted underline (`refusal_galley`, `underline_refusal`). A refused `Enter` leaves the field as typed and focused.
- Field right-click (`context-menus.md` §6.7): *Bind to variable…*, *Extract into variable…* (value into every mode, disabled when bound), *Detach variable* (omitted unbound). *Extract* is one transaction (variable + a first mode if none + bind), then the browser renames it; solid files at full alpha, `%` staying the bind's.
- Focused, a chip consumes `Backspace`/`Delete` as detach (so the keymap never deletes the layer) and hands any other key to the field's buffer as the start of a literal. A hex typed over a binding writes the literal outright (`build::set_brush_at_all`), not through `edited_brush`'s as-drawn reading.
- A colour swatch popup gains a **Variables** tab (4th paint kind; picker width 272). `OndinApp::variables_face`: search plus every colour variable under group headers, row = swatch, elided name, hex in the layer's mode, current checked; click binds keeping `%`. A bound paint opens on it. *Solid* over a binding detaches (`detach_field`); *Linear*/*Radial* convert the drawn brush, which detaches. Where the face can't be named (selection rows whose targets disagree; the *All* row) *Solid* writes as drawn, which is kept: it changes nothing drawn and a `%` ≤ 100% can't draw more opaque than its variable.
- Styled card: collapses to one 28-high capsule (preview, name, summary, *Detach* on hover); the five slot cards' headers gain a `⋯` after the `+` (`ui::HEAD_MORE_W`, 5 gap): *Apply style…*, *Create style…* (*as a copy…* when styled, *…from these N layers…* over several; off over *Mixed*, a partly styled card, or disagreeing lists), *Detach style*. The `+` hides while any target is styled, except under an edit.

**Per-field doors**
- **Paint row / corners** (`FieldKey::Paint`, `Radius`, `Corner`): swatch shows the resolved colour and its `%` is the binding's alpha. Each corner binds alone in the per-corner disclosure (`FieldKey::Corner` in `CornerVars` order; `build::detach_corner_ops` leaves the other three); the all-corners field is the chip only while all four share a variable. The radius `DragValue` lays out its own text, so it hands `--` to the chip's retype buffer, which detaches before its write only if a chip was typed over. **A corner's binding slot is `Corner::var_slot`** (inspector order TL,TR,BL,BR mapped to `CornerVars`' TL,TR,BR,BL) — never a cast. On an instance a corner binding is an override of the radius field (mark joins binding and literal via `OverrideMark::and`; ↺ writes the main's `SetCornerVars` beside its radii).
- **Gaps/padding** (`panels/layout.rs`, `FieldKey::Spacing { id, slots }`, a bit per `SpacingVars` place; `number_chip`, `number_retype`, `spacing_doors`): bound gap field's CSS name gives way to the chip; opposite sides bound apart open per-side padding rows; on instances the binding's mark joins the literal's.
- **Visibility** (`FieldKey::Visible`, never typed): bound, the identity card's eye sits in a 22×18 capsule, click writes the other value (commit detaches), right-click is the field menu. The Properties card's Boolean switch uses a 38×22 capsule when every layer the property views is bound; the layers panel keeps a bound layer's eye drawn at rest in a 22×18 capsule.
- **W/H** (`FieldKey::Size { id, axis }`, only on axes `build::bindable_size_axes` calls hand-set; the multi card's W/H take none). ↺ on an instance writes the main's `SetSizeVars` beside its size.
- **Text** (`FieldKey::Content` typed, `FieldKey::Family` never typed): the *Content* row (`OndinApp::type_content_row`) is in the Type card's live tail beside alignment, so a text style leaves it live; read-only over multi-line text or while the canvas edits the layer (field menu still binds). On an instance, `family_mark`/`content_mark` join binding and literal; ↺ writes both. The canvas session opens on the drawn string. The Properties card's Text row is the chip while every content it views is bound (`variants::bound_chip`; × or `Backspace` detaches each to its drawn string).
- **Frame mode row** (`OndinApp::frame_mode_row`, identity card, `Artboard` only, only in a document with a mode): set → mode name bright; inherited → dim with *· from ‹frame›* or *· default*. Click opens `mode_menu_ui` (*Inherit*, naming what it would inherit, then each mode), one `SetMode` per pick, a rung of `Escape`. `variables::inherited_mode` starts at the **parent**; `Document::mode_at` counts the node itself (the row asks what the frame would read unset). Every frame tag appends *· ‹mode›* when the frame sets one (never inherited). H5's tag elision is not built by decision. A copy's own mode is an override marked on the row (label bright with the dot; ↺ restores the main's). Modes have no glyph.

**The browser** (`panels/variables.rs`)
- Opened by `Shift+S` or the rail's swatches button above the hexagon; opening it or the insert picker closes the other (same anchor); fixed height 460; width 340/436/532 by mode count (scrolls sideways past three modes, by wheel or G3's bar). `Escape` takes an open menu/field first, then the browser. *Variables* and *Styles* tabs, an *In selection* filter, usage counts that select.
- Groups = everything before a name's last `/` (`variable::split_name`), each distinct path one flat header; renaming a group onto one holding a same-named leaf is refused, else merged. `Alt`-click opens/closes all; collapsed groups are the document's, kept per root id for the process (not saved). A usage count is layers whose own fields read the variable, not through an alias (`variable::users`).
- Cells edit in place (`Enter`/defocus commits, `Escape` abandons, `Tab` next mode); an alias is typed `--name` (so a literal string starting `--` can't be typed). Colour cells open the colour popup (`PaintSlot::VarCell`); its Variables tab makes the cell an alias and greys rows that would loop. Picker drags preview in the picker and browser cell (`OndinApp::var_cell_preview`) and on every layer reading the variable through `absorb`, which re-resolves bound nodes against the table with one cell changed (`Variables::with_cell`).
- Deleting goes through core verbs putting detaches in the deleting transaction (`variable::remove_ops`, `remove_mode_ops`); the commit refuses a bare removal. A first variable brings the document's first mode. Refusals are B4's manner: one sentence above the table, refused text dim over dots.
- Boolean variable: `+` menu, `true` in every mode; cell is a 12-pt box then *True*/*False*; click on box toggles, on the word types (`true/false`, `yes/no`, `on/off`, `1/0`). String variable: `+` menu, default "Text" in every mode; cell drawn quoted, line breaks as spaces, typed bare and untrimmed.
- *Styles* tab groups by card; row = preview, whole name, count; menu *Rename*, *Edit*, *Select N layers*, *Delete*. **Edit is an edit mode, not a card in the browser**: it selects the style's users and sets `EditorSession::style_edit`; their card opens live under an *editing* capsule; `style::edit_through`, first in `commit_inner`, turns a write of the slot on a user into one `SetStyleValue`, which `settle` writes onto every user. A style with no users can't be edited; the edit ends with *Done*, `Escape`, the style's removal, or a selection holding a non-user. A door-made detach says *Detached X* on the floating status (`session::styles_detached`). **No preview runs `settle`**: the picker's and an edit's previews write the lists themselves, and a preview carries the style's `write_ops` beside the binds, which `absorb` no-ops. *Create* names the new style in the capsule, `Escape` undoing it (`escape_styles`).

**Type card as a style card.** *Ag* preview, `Family · size` summary. Its alignment row and popup opener are a `tail` drawn after the state's rows (also under a collapsed capsule), so they stay live under a text style; the popup locks the Character tab's held sections where read-only (Colour and Language rows live, as a text style holds neither; Paragraph and Box live). Over a live session's non-empty selection its rows are live and write spans, keeping the style; *Apply* over a live session re-opens the editor. On an instance a text-styled layer's five held fields carry no mark of their own (`type_marks`); *Reset Type* resets them. It also draws over **several text layers**: writes fan out per layer (`one_char_attrs_tx` per layer, never the first layer's style broadcast) in one transaction; fields read *Mixed* where layers disagree (the variant label compares faces whole including axes — `faces_disagree`; Auto line height compares the lines each layer lays — `line_height_mixed`); the family row is the picker reading the drawn family; no override marks, no *Content* row, no popup. *Edit* on a text style selects every user.

**Container card as a style card.** Capsule preview is the display glyph turned with direction (`styles::layout_glyph`: Phosphor *columns* for a row, *rows* for a column, *grid-four* for a grid); summary the direction and main-axis gap (*Column · 6*, *Row · bound gap*, grid *Grid · c × r*).

### Kits' variables and styles

A vendored kit's variables and styles sit **in the consumer's own tables**, each minted the consumer's id and carrying `origin: Option<VarOrigin | StyleOrigin>` (kit, id in the publish, version) — the key an update and second insert match on (`by_origin`). The document's own are `Variables::local`.

- **Kit modes**: `Variables::kits` holds `KitModes { name, modes: [KitMode { id, name, from }], map }` per kit; a kit's variable has a cell in each mode of its kit and no other; `Variables::mode` never answers one.
- **Which column a layer reads** (`Variables::kit_mode`, via `Document::mode_for_in`, at every step of an alias walk): the kit's own mode if the nearest mode-setting frame sets one, else the hand-set map entry for the document's mode in force, else the kit mode of that mode's name, else the kit's first. The mapping is built in the direction a read needs.
- **Rules**: a vault node binds only kits' variables and styles and sets no document mode; a kit's variable aliases only its own kit's; a kit's style reads only kits' variables; names unique per kit; mode ids unique across the document and every kit.
- **One planner, `tokens::plan`**, lands what a set of nodes reads for `kit::vendor`, `kit::update_all` and the carrying paste (`Carried::tokens`, matched by **origin, never by name**, kept by `land` to point at the vendored copy). `update_all` with `sync` rewrites the kit's whole holding (`SetVariable`, `SetKitModes`, `SetStyleName/Value/Origin`), keeps hand-set entries while their target survives, removes what the publish dropped (detaching its users), and resets frames on a removed kit mode. A live copy bound as its main is **not** rewritten — the commit's follow carries it, or it would read as an override (`tokens::reads_as_its_source`, `tokens::alike`: fills/strokes matched by item id, a vault main's binding to the document's fork counted alike, styles likewise).
- A held kit's record is reused when it covers the source's modes (a new variable fills extra columns from the source's default); `KitError::Modes` when it lacks one; the kit's own document maps to its own variables, never copies. *Accept all* retries with a `Modes`-named kit moved ahead.
- **A publish freezes a top's and variant's own visibility** to what it shows, so a main root's binding there carries no variable. A kit's frozen copy keeps its bindings and carries their table, except that.
- ***Make local*** forks what the revealed main's bindings read: document-owned copies named `Kit/name`, marked `forked` with the kit variable/style they came from (so a second *Make local* reuses them); each document mode gets the cell `kit_mode` read there (a document with no modes takes the first forked kit's by name; every other held kit's default is pinned to its first mode); the main's bindings are rebound and the follow carries them to its instances; a nested kit instance keeps the kit's.
- Saved in v8 (`VariablesDto::kits`, optional origins and fork marks).
- **Chrome**: the `--` list, the swatch Variables face, the browser and *Apply style…* list kits' last, each under its mark and name. The browser's kit header carries the mapping per mode column (*Day →* under *Light*; a click opens the kit's modes and *Match by name*); kit groups fold under `\u{2}kit\u{2}path`; rows are inert (count selects users; no rename, cells, menu or *Duplicate*). A kit's style offers *Select* only. The update toast counts variables and styles updated/removed; the update popover's summary names them old → new with a removal's detach count; a kit header reads *· v8 → v9* while an update waits. Not built: a kit variable no held main reads can't be bound.

### Not built / deferred
- **CSS-custom-property export** belongs to code export (HTML/CSS and framework code), a later feature: a tree-shaken `tokens.css` with the default mode on `:root` and others as `[data-mode="…"]`, styles resolved into each user with variables kept as `var()` (§15 D1098). §7 writes paint as presentation attributes today.
- Not yet D1038's: the swatch Variables face's kit group and row hover preview.

### Traps
- **Every reader must resolve.** A reader of the document's own kind (not `Resolved`'s used kind, `resolved_*`, `shown`, `drawn_opacity`) sees the bound literal (0, `true`, empty) and silently draws wrong.
- **Resolved outputs clear their bindings** (`resolved_paint_in`, `resolved_effects_in`): previews hold resolved values that the scene would otherwise resolve again against the committed table.
- **Two-half rule for "keep" passes**: drawn value *or* own literal stays bound. Either half alone detaches fields nobody edited (Scale tool, per-corner ↺, whole-list rebuilds). Visibility and opacity deliberately use one half.
- **`style::settle` runs first and last** and is the only place "styled or not as a whole" lives; no preview runs it.
- **`commit_inner`'s no-op test also drops a bound release's identical commit**, so a guard added only there looks removable but isn't.
- **Style vs variable resolution differ on purpose**: variables resolve at read; styles are copied into the layer at commit.
- **Corner slot order**: inspector TL,TR,BL,BR vs `CornerVars` TL,TR,BR,BL — use `Corner::var_slot`.
- **`inherited_mode` vs `mode_at`**: start at parent vs count the node itself.
- **Kit variables are never matched by name** in the carrying paste or update: match by origin.
